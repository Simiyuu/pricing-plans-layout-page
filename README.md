# Responsive Pricing Plans

A CSS layout project that builds a modern, interactive pricing tier component. This project demonstrates advanced flexbox control, handling wrapping behaviors, and precise box-model sizing to ensure a clean, professional user interface.

## Live Demo
[View the Live Project](https://simiyuu.github.io/pricing-plans-layout-page/)

## Technologies & Concepts Used
* **HTML5:** Semantic card structure and unordered lists for feature comparisons.
* **CSS3:** 
  * `display: flex` and `flex-wrap: wrap` for dynamic, multi-line container layouts.
  * `box-sizing: border-box` to perfectly constrain paddings and borders within fixed dimensions.
  * `transform: scale()` and `box-shadow` for smooth, interactive hover states.
  * CSS transitions for fluid animations.
